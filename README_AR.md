# Open End Technology — الموقع الرسمي

نسخة جاهزة للنشر من موقع الشركة، بالهوية الرسمية المستوحاة من الشعار الأسود والأخضر النيون.

## محتويات المشروع

- `index.html`: الموقع وجميع الأقسام.
- `assets/styles.css`: تخطيط الموقع الأصلي.
- `assets/neon-theme.css`: الهوية البصرية الجديدة بالكامل.
- `assets/app.js`: العربية/الإنجليزية، قائمة الهاتف، تصفية الخدمات، عروض الأنظمة التفاعلية، وإنشاء رسالة WhatsApp من نموذج الاستفسار.
- `assets/open-end-logo.png`: الشعار مأخوذ من الصورة المرسلة، على خلفية دائرية نظيفة.
- `assets/open-end-icon.png`: أيقونة المتصفح.
- `assets/open-end-social.png`: صورة معاينة مشاركة الرابط.
- `DEPLOY_GITHUB_HOSTINGER.md`: تعليمات النشر عبر GitHub + Cloudflare Pages وربط دومين Hostinger.

## تجربة الموقع

افتح `index.html` مباشرة في المتصفح بعد فك الضغط. لا تحتاج إلى قاعدة بيانات ولا إلى Node.js.

بديل Windows PowerShell:

```powershell
cd "C:\\your-path\\open-end-technology-v2"
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## كيفية التعديل

- تعديل محتوى الصفحة العربية: `index.html`.
- تعديل الإنجليزية: كائن `english` في `assets/app.js`.
- ألوان الهوية: المتغيرات في بداية `assets/neon-theme.css`.
- الرقم وروابط المشاريع: `assets/app.js` والروابط الموجودة في `index.html`.

## ملاحظات تقنية

- نموذج الاستفسار **لا يخزن البيانات** ولا يرسلها إلى سيرفر؛ ينشئ رسالة ويحوّل الزائر إلى WhatsApp.
- الخدمات الموضحة (مثل أنظمة معارض السيارات والصالونات والمحفظة الرقمية) معروضة كحلول **يمكن طلب تطويرها**؛ لا تدّعي الصفحة أنها منتجات منشورة بالفعل.
- اعتماد بطاقات Apple Wallet وGoogle Wallet في مشاريع العملاء يتطلب استيفاء شروط مزودي المنصتين.
- الرسومات داخل أقسام بعض المشاريع هي صور وواجهات توضيحية، وليست صوراً حقيقية من كل الأنظمة.
- لم تتم أي تغييرات على DNS أو استضافة جيتك؛ يلزم ربط النطاق الفرعي يدوياً بعد نشر الموقع.
